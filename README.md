# Sanatan Seva Website

Updated static website for GitHub Pages.

## Files
- index.html
- style.css

## Deploy / update on GitHub Pages
1. Replace the existing `index.html` and `style.css` in your repository.
2. Commit changes to the `main` branch.
3. GitHub Pages will redeploy automatically.

## Included
- Puja and Sanskar services
- 2026 Vivah Muhurat planning calendar
- 2026 Griha Pravesh planning calendar
- 2026 major Hindu festival calendar
- WhatsApp booking buttons
- Hyderabad service area
- Responsive mobile/desktop layout

Muhurat dates are presented as planning references and should be confirmed for the actual ceremony location and final Panchang requirements.


## Hero image
The homepage hero card uses `images/sanatan-seva-hero.png` supplied for the Sanatan Seva website.


## Responsive design
The site is optimized for desktop, tablet and mobile screens. The navigation becomes a mobile menu, cards collapse to one/two columns, the hero image scales proportionally, and buttons become full-width on small phones.
